## Linux 基础命令

Linux 提供了丰富的命令行工具，掌握一些基础命令对于日常使用和系统管理非常重要。本文将介绍一些常用的 Linux 基础命令。

### 文件和目录操作

*   **`ls`**: 列出目录内容。
    *   `ls`: 列出当前目录的文件和目录。
    *   `ls -l`: 以详细列表形式列出。
    *   `ls -a`: 列出所有文件，包括隐藏文件。
    *   `ls -h`: 以人类可读的格式显示文件大小。
    *   `ls -t`: 按修改时间排序。
*   **`cd`**: 切换目录。
    *   `cd 目录名`: 进入指定目录。
    *   `cd ..`: 返回上一级目录。
    *   `cd ~`: 返回用户主目录。
    *   `cd /`: 进入根目录。
*   **`pwd`**: 显示当前工作目录的路径。
*   **`mkdir 目录名`**: 创建新目录。
    *   `mkdir -p 目录名/子目录名`: 递归创建目录，即使父目录不存在也会创建。
*   **`rmdir 目录名`**: 删除空目录。
*   **`rm 文件名或目录名`**: 删除文件或目录。
    *   `rm -r 目录名`: 递归删除目录及其内容。
    *   `rm -f 文件名`: 强制删除文件，无需确认。
    *   `rm -rf 目录名`: 强制递归删除目录及其内容，请谨慎使用。
*   **`cp 源文件 目标文件`**: 复制文件。
    *   `cp -r 源目录 目标目录`: 复制目录。
*   **`mv 源文件 目标文件`**: 移动或重命名文件或目录。

### 文件内容操作

*   **`cat 文件名`**: 查看文件内容（全部显示）。
*   **`less 文件名`**: 分页查看文件内容，适合查看大文件。
    *   空格键：向下翻页。
    *   `b`键：向上翻页。
    *   `/关键词`: 搜索关键词。
    *   `q`键：退出。
*   **`head 文件名`**: 查看文件头部内容（默认前 10 行）。
    *   `head -n 行数 文件名`: 查看文件前 N 行。
*   **`tail 文件名`**: 查看文件尾部内容（默认后 10 行）。
    *   `tail -n 行数 文件名`: 查看文件后 N 行。
    *   `tail -f 文件名`: 实时追踪文件尾部内容，常用于查看日志文件。
*   **`echo 内容`**: 输出内容到终端或文件。
    *   `echo "内容" > 文件名`: 将内容写入文件（覆盖）。
    *   `echo "内容" >> 文件名`: 将内容追加到文件末尾。
*   **`grep 关键词 文件名`**: 在文件中搜索关键词。
    *   `grep -i 关键词 文件名`: 忽略大小写搜索。
    *   `grep -r 关键词 目录名`: 递归搜索目录下的文件。

### 系统操作

*   **`ps`**: 查看进程状态。
    *   `ps aux`: 显示所有用户的详细进程信息。
*   **`top`**: 实时显示系统资源占用情况，包括 CPU、内存等。
*   **`kill 进程ID`**: 结束指定进程 ID 的进程。
*   **`shutdown`**: 关机。
    *   `shutdown -h now`: 立即关机。
    *   `shutdown -r now`: 立即重启。
*   **`reboot`**: 重启。
*   **`clear`**: 清空终端屏幕。

### 用户和权限

*   **`whoami`**: 显示当前用户名。
*   **`sudo 命令`**: 以管理员权限执行命令。
*   **`chmod 权限 文件名或目录名`**: 修改文件或目录的权限。
    *   例如：`chmod 755 文件名`。
*   **`chown 用户名 文件名或目录名`**: 修改文件或目录的所有者。

### 网络操作

*   **`ping 目标地址`**: 测试网络连通性。
*   **`ifconfig` 或 `ip addr`**: 查看网络接口配置信息。
*   **`netstat`**: 显示网络状态信息。
*   **`ssh 用户名@目标地址`**: 远程登录到 Linux 服务器。

这只是一些 Linux 基础命令的介绍，Linux 命令非常强大和灵活，希望这篇文章能帮助您入门。 更多命令可以通过 `man 命令名` 或 `命令名 --help` 来查看帮助文档。
